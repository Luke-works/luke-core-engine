List Groups ​

Returns a list of groups that fulfill given parameters.

Request ​

GET /engine-rest/group

Headers ​

HeaderValueRequired
AuthorizationBasic YWRtaW46YWRtaW4=Yes
X-Tenant-Idluke_defaultNo (tenant-exempt)

Query Parameters ​

ParameterTypeDescription
idstringFilter by group ID
idInstringComma-separated group IDs
namestringFilter by name
nameLikestringFilter by name pattern (% wildcard)
typestringFilter by group type (e.g., ORGANIZATION, WORKFLOW)
memberstringFilter groups by member user ID
memberOfTenantstringFilter groups that are members of a tenant
sortBystringid, name, type
sortOrderstringasc or desc
firstResultintegerPagination offset
maxResultsintegerPagination limit

Response ​

Status Codes ​

StatusDescription
200Request successful
400Invalid query parameters

Response Body ​

json
[
  {
    "id": "accounting",
    "name": "Accounting",
    "type": "ORGANIZATION"
  },
  {
    "id": "sales",
    "name": "Sales Team",
    "type": "ORGANIZATION"
  }
]
